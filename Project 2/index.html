How to Play

  • Click a tile next to the empty space to slide it.
  • Reassemble the picture in reading order to solve.
  • Use a Magic Hint if you get stuck (limited uses).
  • Solving saves your score to the leaderboard.

Project Overview

The Fifteen Puzzle is a classic 4×4 sliding tile challenge: fifteen numbered pieces and one empty space, shuffled into a solvable arrangement that only unscrambles through careful planning. This build wraps that mechanic in three beach-themed picture puzzles — Tide, Breeze, and Sun — each reconstructing a distinct scene as you solve it.

Client-Side Engineering

JavaScript drives shuffle generation (guaranteed solvable), move validation, solved-state detection, timing, move tracking, and the Magic Hint system.

Server-Side Integration

A small PHP API persists scores to MySQL (player, mode, moves, time). If the database is unreachable, the app automatically falls back to local storage so play is never blocked.
